Support

Need help with Pluginflex Photo Manager? Start with the steps below.

Login or confirmation email

  1. Check that the email address is entered correctly.
  2. Check your inbox and spam/junk folder for the newest confirmation email.
  3. Open the newest confirmation link on the same device, then return to the photo library and sign in.
  4. If login still fails, note the exact on-screen error. Never send anyone your password or verification link.

Upload or display problem

  • Use a supported image format: JPEG, PNG, WebP, GIF, or HEIC.
  • Each photo must be 10 MB or smaller.
  • Check your internet connection and tap Refresh library.
  • Keep a backup of important originals on your device.

Privacy or deletion request

Use the Delete control on a photo to remove it from your library, then check that it no longer appears after refreshing. For account-level or other data requests, include the account email and a clear description when contacting the project maintainer through the project issue page. Do not include passwords, private photo links, or sensitive images in a public issue.

Support page status: self-help guidance is available. A dedicated support inbox and automated account-deletion workflow have not been verified as configured.
